
# Personal Mini-Toolkit

## Project Description

The Personal Mini-Toolkit is a Python program that combines three useful tools in one menu-driven application. It helps users perform calculations, manage tasks, and check whether numbers are even or odd.

## Tools Included

### 1. Simple Calculator
The calculator performs addition, subtraction, multiplication, and division on two numbers.

### 2. To-Do List
The to-do list allows users to add tasks, view their tasks, and remove tasks while the program is running.

### 3. Even or Odd Checker
This tool checks whether a whole number is even or odd using the modulo operator (%).

## How to Run the Program

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   `py toolkit.py`

5. Select a tool from the menu.
6. Follow the instructions displayed on the screen.
7. Choose option 4 to quit.

## Testing

The program was tested using the following cases:

- Calculator addition with 10 and 5.
- Adding, viewing, and removing tasks in the to-do list.
- Checking an even number and an odd number.
- Entering an invalid menu choice.
- Selecting the quit option.

## Reflection

I enjoyed building this project because it helped me combine the Python concepts I learned. The hardest part was organizing the menu and making each tool work correctly. The most challenging bug was handling invalid user input without crashing the program. I learned how to use loops to repeat actions and conditionals to make decisions. I also learned how lists can store tasks that change while a program runs. Testing each menu option helped me find and correct mistakes. With one more week, I would add a number-guessing game and save tasks to a file so they remain available after the program closes.
